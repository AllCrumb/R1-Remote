# R1 Remote — управление Windows с кольца Even R1

**R1 Remote** — независимое приложение для Windows 11, которое использует кольцо **Even Realities R1** как Bluetooth LE-контроллер компьютера.

[English](../README.md) · [Установка](INSTALLATION.md) · [Безопасность](SAFETY.md) · [Изменения 1.3.0 RC](RELEASE_NOTES_1.3.0_RC.md)

## Возможности

- Прокрутка Windows вверх и вниз жестами R1.
- Автоматическое переподключение после временной потери Bluetooth-связи.
- Нативное приложение с выбором кольца, состоянием подключения и настройками.
- Настраиваемые действия и экспериментальные профили для приложений.
- Интерфейс на русском, английском, французском и немецком.
- Безопасный запуск: управление Windows выключено, пока пользователь его не включит.
- Возврат к G2 после завершения сеанса Windows без принудительного восстановления адресов. Этот сценарий проверен на одном комплекте; поведение других прошивок ещё неизвестно.

Для сеанса управления Windows телефон и очки Even G2 не нужны. Одновременно управлять очками и компьютером одним кольцом, как правило, нельзя: может потребоваться переключить подключение.

## Требования

Windows 11 x64, адаптер Bluetooth Low Energy, кольцо Even Realities R1. Совместимость разных версий прошивки и BLE-адаптеров ещё изучается.

## Где взять MAC-адреса G2

При первой настройке R1 Remote нужны **два Bluetooth MAC очков**, а не MAC самого кольца.

1. Открой штатное приложение **Even** на телефоне и выбери свои очки **Even G2**.
2. Перейди на экран **Glasses info** (информация об очках).
3. Найди строку **Bluetooth MAC**. Под ней отображаются **два адреса**, каждый в формате `XX:XX:XX:XX:XX:XX`.
4. Перепиши **верхний адрес** в поле **G2 №1** программы R1 Remote, **нижний** — в **G2 №2**, сохраняя порядок отображения. Проверь все 12 шестнадцатеричных символов каждого адреса.

На экране Even адреса не помечены как левый и правый: не пытайся определять стороны по порядку. Эти значения взяты из информации об очках, но **не являются независимым чтением заводских target-слотов R1**. Не публикуй их вместе с серийным номером на форумах или в GitHub Issues. Подробнее — в [инструкции установки](INSTALLATION.md#finding-the-two-g2-bluetooth-mac-addresses).

## Статус

**1.3.0 RC — тестовая версия, не GA.** Прокрутка и переподключение после потери радиосвязи работают на проверенном комплекте R1 и Windows 11. После серии ошибок приложение сохраняет управление включённым и повторяет попытки подключения с интервалом около 10 секунд. Проверки на других кольцах, обновление и откат ещё не завершены.

В отдельных случаях восстановление C1 требует записи в targets кольца: приложение запрашивает подтверждение и разрешает не больше одной такой операции за запуск. Это может прервать соединение с G2. Автоматической обратной записи при выходе нет.

**[Скачать 1.3.0 RC1](https://github.com/AllCrumb/R1-Remote/releases/tag/v1.3.0-rc.1)** можно на странице GitHub Releases. Установщик без цифровой подписи, поэтому перед запуском проверь SHA-256.

## Обратная связь

Ошибки можно описать в [GitHub Issues](https://github.com/AllCrumb/R1-Remote/issues). Указывай сборку Windows, версию прошивки кольца, модель Bluetooth-адаптера и последовательность действий. Удаляй MAC-адреса, Device ID, имена пользователей и приватные данные из логов перед публикацией.
