# R1 Remote — управление Windows с кольца Even R1

**R1 Remote** — независимое приложение для Windows 11, которое использует кольцо **Even Realities R1** как Bluetooth LE-контроллер компьютера.

[English](../README.md) · [Установка](INSTALLATION.md) · [Безопасность](SAFETY.md) · [Изменения 1.3.0 RC](RELEASE_NOTES_1.3.0_RC.md)

## Возможности

- Прокрутка Windows вверх и вниз жестами R1.
- Нативное приложение с выбором кольца, состоянием подключения и настройками.
- Настраиваемые действия и экспериментальные профили для приложений.
- Интерфейс на русском, английском, французском и немецком.
- Безопасный запуск: управление Windows выключено, пока пользователь его не включит.
- Возврат кольца к G2 без обязательной автоматической перезаписи Bluetooth-адресов. Это подтверждено для одного испытанного комплекта, а не для всех устройств.

Для сеанса управления Windows телефон и очки Even G2 не нужны. Одновременно управлять очками и компьютером одним кольцом, как правило, нельзя: может потребоваться переключить подключение.

## Требования

Windows 11 x64, адаптер Bluetooth Low Energy, кольцо Even Realities R1. Совместимость разных версий прошивки и BLE-адаптеров ещё изучается.

## Статус

**Версия 1.3.0 — Release Candidate / Preview, не GA.** Основные жесты Windows и возврат к G2 подтверждены оператором на реальном оборудовании. Полная проверка обновления/отката, нескольких колец и негативных Bluetooth-сценариев ещё не закончена.

**Публичный установщик в этом репозитории пока не опубликован.** Не скачивай EXE из комментариев или неофициальных зеркал.

## Обратная связь

Ошибки можно описать в [GitHub Issues](https://github.com/AllCrumb/R1-Remote/issues). Указывай сборку Windows, версию прошивки кольца, модель Bluetooth-адаптера и последовательность действий. Удаляй MAC-адреса, Device ID, имена пользователей и приватные данные из логов перед публикацией.

## Правовой статус

Это неофициальный независимый проект, не связанный с Even Realities. В этом GitHub-репозитории сейчас опубликована только документация. Исходный код не открыт и лицензия на его использование не предоставлена.
